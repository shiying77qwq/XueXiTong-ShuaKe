# 学习通视频助手 · 0.3

Windows本地工具，通过学习通App正常播放视频，确认任务完成后切换小节。无需模型API或Python。

**当前状态：本次约定范围验收通过。** 190项模块检查和12项打包自测通过；同一正式构建已完成3.3→4.1、4.1→4.2两轮真实切换，后者成功处理目录滚动中的标题位置变化。普通GUI的开始和停止快捷键也已实测，证据与范围见 TEST-REPORT.md。

## 使用

1. 打开本目录的 StudyVideoHelper.exe。
2. 在学习通中登录并进入要开始的小节视频页，将学习通留在前台。
3. 按 **Ctrl+Alt+F11** 开始连续处理。也可点击助手中的“开始”；如Windows拒绝交接焦点，回到学习通再使用快捷键。
4. 按 **Ctrl+Alt+F12** 停止。停止助手后，学习通的视频可能仍在继续播放。

运行期间保持学习通在前台，不锁屏、睡眠或最小化。需要操作其他软件时，先停止助手。普通流程从当前小节向后处理；要覆盖所有后续视频，应先打开最早未完成的视频页。

“验证一次切换”要求当前视频明确未完成：等待它正常播放并完成，再由程序打开下一段、确认新页、正常播放，取得实际进度前进后记录PASS并结束，不继续第三段。

## 播放与切换

- 先读取实际进度和时长。预计结束前20秒开始频繁检查任务点；最后阶段约每2秒检查一次。只有页面明确显示完成且进入最后20秒，才切换。网络和读取耗时会影响时刻。
- 已完成视频会跳过；目录任务数量可能同时包含测验，不能单凭数量判断视频是否完成。
- 下一视频的标题、任务和播放器状态需经过两次完整读取确认，再点击普通播放按钮。时间缺失或异常跳变最多复核两次，持续异常则停止。
- 点击目录前读取标题当前位置并核验实际命中；标题离屏时，仅在已确认的目录内有限滚动。真实遮挡、目标变化、窗口失焦或用户按下修饰键时停止。
- 运行日志保存在 logs/，记录动作和失败原因。控件诊断只保存在本机，不随交付ZIP收录。

只处理唯一视频任务点、唯一播放器的页面。多任务点、多个播放器、同名独立标题、完成状态不明或自动播放目标无法确认时，会停止供人工检查。登录和选择课程由用户完成。本版范围为视频播放与切换，不填写或提交测验、考试、作业、问卷，不调整倍速、拖动进度或生成播放记录请求。

进度40秒不前进、意外暂停、新小节25秒未稳定、点击播放后12秒未确认播放或结束后60秒仍无完成标记时停止。单次页面读取有45秒上限；取消后仍可能在后台返回的只读调用不会触发点击。
